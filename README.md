<h3>QR Tree Studio — A QR code that grows</h3>

<a href="https://qr-tree-studio.vercel.app"><picture><source media="(prefers-reduced-motion: reduce)" srcset="assets/projects/qr-tree.jpg"><img src="assets/projects/qr-seasons.gif" width="1200" alt="QR Tree Studio showing a summer voxel tree, URL input and seasonal controls."></picture></a>

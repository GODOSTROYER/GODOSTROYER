# Product

## Platform

web

## Stack

GitHub profile README: Markdown, supported HTML, self-contained SVG, Python standard library, GitHub Actions. A static local preview is a review tool, not a replacement for the README.

## Users

Visitors to Arnav Bule's GitHub profile who want to understand his public projects and open their source or live demonstrations. Collaborators and prospective employers are an assumed secondary audience, not a confirmed job-search claim.

## Product Purpose

Build a distinctive, accurate, polished GitHub profile README with an animated introduction, selected real work, and automatic updates.

## Operating Context

Profile owner: GODOSTROYER / Arnav Bule. Profile repository: GODOSTROYER/GODOSTROYER. Public repository evidence supplies project descriptions; no private work is published.

## Capabilities and Constraints

GitHub sanitizes README HTML. Script-driven interaction belongs in the local preview or linked project demos. The shipped identity uses standalone SVG and responsive picture sources. Main content stays readable without motion. Dynamic content preserves the last successful output.

## Brand Commitments

The identity pairs a developer terminal with an original visual motif, a concise showcase, automatic updates, and one memorable flourish.

## Evidence on Hand

The public GitHub profile confirms identity. Project descriptions were checked against their public repositories and demonstrations. Image sources are recorded in assets/projects/SOURCES.md; public activity is stored in data/activity.json. Claims about users, benchmarks, education, employment, availability, or accomplishments must be grounded in public evidence or omitted.

## Product Principles

- The projects are the substance; motion makes the introduction memorable.
- Content is factual, readable, and linked to the work.
- Match GitHub's native capabilities and theme changes.
- No remote image service is required to render the profile.
- An external API failure must not replace successful content with an error graphic.
